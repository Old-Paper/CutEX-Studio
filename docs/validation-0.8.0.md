# 0.8.0 验收说明

## 工作流程

导入自动粗剪 → 原片校对时按 X 保留/删除 → 成片预览 → 保存项目 → 导出。

- 手动缩短、拆分、恢复的片段在保存重开后保持原样。
- 重新分析保留手动决定，并进入撤销历史。
- 项目原子保存并保留上一个 `.bak`，修改后生成本地恢复快照。
- 普通滚轮平移、Alt+滚轮以鼠标为中心缩放、总览条导航。
- 真实波形多级缓存、可见区域绘制，密集删除区域不叠加红色底色。
- 快速模式保留 concat 时间戳，并补偿切点音频间隙，避免累计偏移。
- 导出使用临时文件，校验流、时长、开头/中间/结尾可解码性后交付；不覆盖已有成品。

## 可重复验证

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm prepare:electron
pnpm smoke
$env:CUTEX_BENCHMARK = '1'
pnpm exec vitest run tests/benchmark.test.ts
```

`pnpm test` 自动生成测试媒体，真实 FFmpeg 用例无需设置环境变量。包含七种格式、600 个短音频切点、可用 GPU/不可用 GPU 回退、40 次 B 帧视频切段后的闪光与提示音同步（误差不超过 25 fps 的一帧）、多音轨预览、已有文件保护和取消。

`pnpm smoke` 运行真实 Electron 界面及 IPC，检查导入、自动分析、拖动后画面位置、缩放、滚动、全片导航、两种试听模式、X/撤销、保存重开和导出。原生文件选择对话框使用固定测试路径替代选择，不能算手工点击原生对话框的验收。

## 性能对照

Windows 本机、FFmpeg 8.1.1；15 分钟 320×180、25 fps 合成素材，60 个相同保留区间，输出 120 秒。所有结果包括输出校验耗时。

| 模式 | 耗时 | 输出时长 |
| --- | ---: | ---: |
| 高精度 CPU | 34.47 秒 | 120.00 秒 |
| 快速 CPU | 5.09 秒 | 120.00 秒 |
| 快速 NVIDIA | 4.77 秒 | 120.00 秒 |

两种 CPU 模式使用相同 x264 参数。GPU 编码器的画质参数不等价，不能直接作为画质相同的速度比较。合成小分辨率素材结果不代表 1080p/4K、HEVC、可变帧率或不同磁盘上的固定提速倍数。

## 运行与发布边界

- Electron 44.9.3，Vite 6.4.5，Vitest/coverage-v8 4.1.12，electron-builder 26.15.3；依赖由锁文件固定。
- 依赖检查剩余 1 条中等告警：构建链 `sprintf-js` 的不受限格式精度问题（GHSA-hp3w-g68c-fv3c），上游暂无修复版。没有隐藏或忽略该告警；该依赖不属于应用运行时依赖。继续关注上游。
- 仍需外部 FFmpeg/FFprobe，首次启动有环境检测；便携版没有捆绑 FFmpeg。
- 未购买代码签名证书；没有把 SmartScreen 提示等同于构建失败，也不要求用户关闭系统保护。
- 不保证所有媒体编码都可直接预览；不支持的预览编码会明确报错，不播放错误音轨。
- 标签、源代码和安装包必须一一对应。发布先生成草稿与 SHA-256 校验清单，验证后再公开，禁止覆盖旧版本资产。
